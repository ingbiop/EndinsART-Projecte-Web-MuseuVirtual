Projecte final de curs

EndinsART

Museu virtual interactiu

Un museu digital amb tres sales d'exposició, un plànol interactiu, un llibre de visites i més de 25 obres d'art interactives basades en Canvas 2D. Tot construït sense cap framework ni bundler — JavaScript vainilla pur.

🎨

25+ obres Canvas interactives

Cada quadre té el seu propi renderer amb animació, events de ratolí/tàctil i cleanup automàtic de memòria.

♿

Accessibilitat completa

ARIA labels, rols semàntics, focus trap als modals, aria-live per actualitzacions dinàmiques i audioguia per Web Speech API.

🏛️

Art Institute of Chicago API

La Sala 3 carrega obres reals del museu. Les dades es guarden en JSON local com a fallback si l'API no respon.

🔊

Audioguia integrada

Web Speech API llegeix en veu alta les descripcions de cada obra. Control de pausa i reproducció persistent entre pàgines.

🌍

Interfície íntegrament en català

Tot el contingut, etiquetes ARIA, validacions i missatges d'error estan en català (lang="ca").

Tecnologies i eines

Backend

  • PHP 7.4+ — lògica del servidor
  • PDO + MySQL — base de dades amb sentències preparades
  • Endpoints API propis — save-review, get-reviews, get-artic-api, auth-visites
  • Sessions PHP — autenticació d'administrador al llibre de visites

Frontend

  • JavaScript ES6 Modules — arquitectura modular sense bundler
  • HTML5 semàntic — etiquetes natives amb ARIA
  • CSS3 — custom properties, grid, keyframes (2700+ línies)
  • Canvas 2D API — 25+ renderers interactius
  • Web Speech API — audioguia text a veu
  • ResizeObserver — canvas responsiu amb devicePixelRatio

Emmagatzematge navegador

  • localStorage — sales visitades (persistent)
  • sessionStorage — posició de reproducció musical

API externa

  • Art Institute of Chicago — api.artic.edu/api/v1
  • Imatges via IIIF (International Image Interoperability Framework)
  • Caché local en JSON per fallback offline

Fonts i recursos externs

  • Google Fonts — Playfair Display, Cormorant Garamond, Bricolage Grotesque
  • Material Symbols Outlined — icones a les pàgines d'exposició
  • Audio .mp3 propi per a la música de fons

Entorn de desenvolupament

  • XAMPP — servidor local Apache + MySQL
  • Sense npm, sense bundler — mòduls natius del navegador
  • Sense React / Vue / Angular — DOM vanilla pur

Tot construït amb la plataforma web nativa — sense cap dependència externa de JavaScript.

Implementació

Com funciona cada aspecte

🖼️ Fons de la pàgina d'inici
Art Institute API CSS Grid 7 col. CSS Keyframes rAF Parallax

Gradient vermell fosc de fons. L'API retorna IDs d'imatge; home.js construeix 7 columnes CSS Grid, cada una amb les imatges duplicades. Les columnes parells pugen i les senars baixen en scroll infinit (34 s, linear). El pannell hero s'inclina seguint el ratolí via requestAnimationFrame.

🎫 Animació del tiquet
5 fases setTimeout CSS Keyframes classList

En fer clic al CTA: (1) overlay apareix, (2) tiquet llisca de dalt, (3) sacseig (±4px + rotate), (4) esquinçat: la part superior vola cap amunt-esquerra i l'inferior cap avall-dreta, (5) navegació a mapa.php. El tall es fa amb dues <div> separades per una línia perforada CSS.

🗺️ Mapa interactiu
CSS Grid pur localStorage data-room

Sense cap llibreria de mapes. El plànol és un CSS Grid 4×2 amb arcs de portes fets amb border-radius. mapa.js llegeix el localStorage per marcar les sales visitades amb la classe is-visitada. Un comptador mostra el progrés de la visita.

🔍 Cercador al mapa
Promise.allSettled Filtre in-memory ARIA listbox

En carregar la pàgina, mapa.js fa un fetch paral·lel de les 3 fonts de dades (expo1.json, expo2.json, API). Construeix un índex en memòria de títol + artista + sala. A cada keystroke filtra (màx. 8 resultats) i renderitza un dropdown role="listbox" amb ARIA complet. Cada resultat és un deeplink directe a l'obra.

🖱️ Obres Canvas interactives
Canvas 2D ResizeObserver Pointer Events 25+ renderers

Cada renderer rep un element host, crea un <canvas> via createCanvasSurface() (que gestiona DPR i ResizeObserver), afegeix listeners i llança un loop rAF. Retorna una funció de cleanup. Interaccions: arrossegar, pintar, revelar, estirar, sacseja, zoom, puzzle, metaballs, topografia, engranatges i més.

📝 Formulari i ressenyes
Validació doble PDO prepared aria-live Stars CSS

Nom, valoració (radio 1–5 estrelles, CSS pur) i comentari. validation.js valida al client; save-review.php torna a validar al servidor i insereix amb PDO + placeholders. La llista es refresca amb get-reviews.php. Les estrelles i les dates es renderitzen a reviews.js amb HTML escapat i format ca-ES.
